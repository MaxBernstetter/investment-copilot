# 05 User Frontend

The user frontend lets people explore, compare and trace curves. It is a static React single-page app that calls only the public access API and is deployed to GitHub Pages. Users view curves by country and date, overlay curves from different dates, and use a time-travel control to see the platform as it was known at a chosen time.
