# YieldLens

YieldLens turns government bond yield data into an explorable, auditable and historically reproducible dataset. Every value keeps its source, its version history and the time it became known, so a past view can be reproduced exactly. It is a miniature of a group-level yield-curve and risk-parameter platform.
